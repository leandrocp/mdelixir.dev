# MDEx auth.md

The agent-facing resources on mdelixir.dev are public. Agents do not need to register, create an account, or obtain a credential to read them.

## Audience

These instructions are for agents helping users evaluate, install, or use MDEx.

## Registration and provisioning

MDEx does not offer an agent-registration or credential-provisioning endpoint. Access the public resources directly with an anonymous HTTPS `GET` request.

## Authentication

- Supported method: anonymous access
- Credentials: none
- Authorization header: not required
- OAuth scopes: not applicable
